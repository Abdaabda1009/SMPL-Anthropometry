# Runtime dependencies for the GPU image (Dockerfile.gpu).
#
# Same as requirements.txt, minus torch: the pytorch/pytorch base image
# already ships a CUDA-matched torch build. `pip install -r` on top of it
# would see torch in the requirements and — since PyPI's default index only
# carries the CPU wheel under that name — could silently replace the GPU
# build with a CPU one. Omitting the line avoids that entirely; keep this
# file's other pins in sync with requirements.txt by hand when they change.
